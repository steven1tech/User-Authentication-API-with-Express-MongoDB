before run this project you must folllow this steps:
open terminal.
npm init -y
npm i --save-dev nodemon
npm i express --save
npm i express-validator --save
npm i mongoose --save
npm i morgan --save
npm i bcrypt --save

and go to file package.json and goto script object member and give it run script:
"start": "nodemon app.js"

open terminal and write this command:
npm run start

goto postman extension and get api: POST , GET , PETCH , DELETe
